# AntigravityBridge

A Claude Code plugin that drives the Antigravity App (Gemini) from Claude Code.

**It can:**
- start a task in Antigravity and read its progress
- answer the agent's questions and send follow-ups
- list conversations, models and skills

**Install:** `python install_antigravity.py`, then restart Antigravity. Add the folder as a Claude Code plugin.
